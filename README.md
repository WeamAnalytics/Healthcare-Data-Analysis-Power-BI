# 🏥 Healthcare Data Analysis – Power BI

## 📌 Project Overview

This project is a Healthcare Data Analysis and Interactive Dashboard developed using Microsoft Power BI.

The project analyzes healthcare data from multiple related tables to provide insights into financial performance, patients, providers, healthcare services, and revenue trends.

The project includes three interactive dashboards and a data model containing eight related tables.

## 🗂️ Data Model

The Power BI data model contains 8 related tables:

- Patients
- Providers
- Visits
- Procedures
- Diagnoses
- Departments
- Insurance
- Cities

These tables are connected through relationships to support integrated analysis across patients, providers, healthcare services, financial information, and geographic data.

## 📅 Date Table & Time Intelligence

A dedicated Date Table was created to support accurate time-based analysis.

The Date Table was used to analyze data by different time periods and to support Time Intelligence calculations.

Time-based analysis includes:

- Revenue by Year
- Revenue by Month
- Monthly Revenue Trends
- Yearly Revenue Trends
- Time-Based Performance Analysis

Time Intelligence was used to analyze trends over time and improve the accuracy and flexibility of the Power BI analysis.

📅 Date Table & Time Intelligence
A dedicated Date Table was created to support accurate time-based analysis and improve the structure of the Power BI data model.
The Date Table was used to analyze healthcare and financial data across different time periods and to support Time Intelligence calculations.
Time-based analysis includes:
Revenue by year
Revenue by month
Monthly revenue trends
Yearly revenue trends
Time-based comparisons
Time Intelligence techniques were used to analyze trends over time and make the dashboard more effective for financial and business analysis.
